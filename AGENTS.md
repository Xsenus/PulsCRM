# Правила работы агента

- После каждой завершенной задачи перед финальным коммитом увеличивать patch-версию приложения на 1 в `backend/Directory.Build.props` (`VersionPrefix`, формат `major.minor.patch`). Например, `1.0.1` -> `1.0.2`.
- Если пользователь явно просит изменить major или minor, следовать его указанию; иначе увеличивать только patch.
- Если версия уже была увеличена в рамках текущей задачи, повторно ее не поднимать.
- Коммиты делать с логичным сообщением на русском языке.
