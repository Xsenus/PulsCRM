# Документация

- `devexpress-license.md` - как убрать `DX1001`, где должен лежать `DevExpress_License.txt`, нужен ли ключ на IIS и как настроить self-hosted runner.
- `manual-smoke-test.md` - ручной checklist после локального запуска, IIS deploy или rollback: login, dashboard, сотрудники, организации, SMTP, рассылки, очередь, адаптивность и БД.
- `project-analysis.md` - подробный анализ текущего состояния проекта, UI, backend, рассылок, рисков и проверок перед roadmap.
- `project-roadmap.md` - подробный roadmap правок на основании анализа: этапы, приоритеты, критерии готовности и первые задачи.
- `repository-bootstrap.md` - как инициализировать локальный Git-репозиторий и отправить проект на GitHub.
- `whats-new.md` - краткий журнал заметных изменений по задачам.
- `windows-server-2016-iis-autodeploy.md` - как подготовить Windows Server 2016, IIS, self-hosted runner и автодеплой в production.
